# SpiralCore

تطبيق Android أصلي لإدارة الروابط كقواقع رقمية شخصية. الواجهة والمصادقة والتكامل مع نظام Android مكتوبة بـKotlin وJetpack Compose. تُحفظ الروابط والتصنيفات وبذور مظهر القواقع في SQLite محليًا عبر Room؛ لا يوجد خادم أو مزامنة أو إذن إنترنت.

## فتح المكتبة

تستخدم البوابة Android BiometricPrompt بالبصمة القوية أو بيانات اعتماد قفل الجهاز. على Android 11 وما بعده يعرض النظام خيار بيانات اعتماد الجهاز من داخل التدفق، وعلى الإصدارات الأقدم يوجد مسار منفصل لرمز PIN/قفل الجهاز. لا يخزن التطبيق PIN خاصًا به. يتم قفل الواجهة عند انتقال النشاط إلى الخلفية، وتمنع `FLAG_SECURE` لقطات الشاشة، ويُعطّل نسخ بيانات التطبيق الاحتياطي.

## المتطلبات

- Android Studio حديث أو JDK 17 مع Android SDK 35.
- Android 9 (API 28) أو أحدث.
- Gradle Wrapper المضمّن في المستودع.

## البناء والاختبارات

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

يُشغّل GitHub Actions اختبارات Kotlin وبناء APK Debug على مستضيف Android. ملف APK الناتج مخصص للتجربة؛ لا توجد نسخة Release موقّعة.

## نطاق التحقق الحالي

تغطي اختبارات JVM تطبيع الروابط والتحقق منها وتنوع القواقع. يلزم اختبار البصمة وPIN فعليًا على أجهزة Android متنوعة قبل أي إصدار إنتاجي. قاعدة SQLite داخل مساحة التطبيق المحلية وليست SQLCipher؛ حماية البيانات تعتمد كذلك على قفل الجهاز وتشفير Android على مستوى الجهاز، كما أن تعطيل النسخ الاحتياطي لا يمنع استخراج البيانات من جهاز مروّت أو مفتوح.
