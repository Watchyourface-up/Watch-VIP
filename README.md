# DevVault

دفتر محلي خاص لروابط المطورين باستخدام Expo وReact Native وTypeScript.

## المتطلبات
- Node.js 22 وnpm.
- Android: Android SDK/JDK متوافقان مع Expo SDK 54.
- iOS: macOS وXcode؛ لا يمكن التحقق من بناء iOS على Windows أو Linux.

## التشغيل والفحوص
```bash
npm install
npm run typecheck
npm test
npm run lint
python tools/validate_schema.py
python tools/check_secrets.py
```

تشغيل Android محليًا:
```bash
npx expo prebuild --platform android
npx expo run:android
```

تشغيل iOS على macOS:
```bash
npx expo prebuild --platform ios
npx expo run:ios
```

## نموذج الأمان الحالي
- لا حساب ولا واجهة مزامنة سحابية في الإصدار الحالي. لا يحتوي التطبيق على إرسال مقصود للروابط إلى خادم.
- الروابط تقتصر على HTTP/HTTPS وتُفتح بواسطة النظام؛ الروابط التي تتضمن بيانات دخول مضمّنة تُرفض.
- تُحفظ البيانات في قاعدة SQLCipher فقط إذا كان البناء الأصلي يقدم `PRAGMA cipher_version`. خلاف ذلك يرفض التطبيق التهيئة ولا يعود عمدًا إلى قاعدة غير مشفرة.
- مفتاح قاعدة البيانات عشوائي بطول 256 بت ويُحفظ عبر SecureStore/Keychain؛ لا تسجّله ولا تضعه في ملفات المشروع.
- التحذير من الروابط الحساسة heuristic فقط، ولا يمكنه اكتشاف كل سر. لا تحفظ كلمات مرور أو رموز وصول أو روابط ذات صلاحيات.
- واجهة المصادقة تستخدم واجهة النظام الحيوية، لكن التعامل مع تغيّر تسجيل البصمات، والاعتماد الصريح على رمز قفل الجهاز كبديل، يحتاج تحققًا على الأجهزة المستهدفة قبل إطلاق التطبيق.
- الواجهة تُقفل عند انتقال التطبيق إلى الخلفية وتُزال بيانات العرض من الحالة. الحماية من لقطة شاشة Android وطمس App Switcher ليست مفعّلة بالكامل بعد، وiOS لا يتيح منعًا عامًا لكل لقطات الشاشة.
- فحص SQLCipher الحقيقي، وفشل فتح قاعدة بمفتاح خاطئ، والتأكد من عدم وجود بيانات مكشوفة في نسخ احتياطية، كلها اختبارات مطلوبة في بناء أصلي. خيار `useSQLCipher` وحده لا يثبت التشفير.
- لم تُضف شيفرة Kotlin أو Swift أو Rust شكلية؛ ستضاف الوحدات الأصلية عند الحاجة الفعلية وبعد اختيار آلية موثوقة للتحكم في سلوك المنصة.

## حدود الإصدار
هذا أساس تطوير، وليس إصدارًا جاهزًا للنشر. لا تُعلن جاهزية أمان أو بناء ناجح حتى تنجح CI، ثم تُنفّذ اختبارات Android أصلية على جهاز فعلي واختبارات iOS على macOS/Xcode.
